# 六、你后面最该提升的能力

## 1. 提示词能力

你已经开始具备了。后面要学会这样表达：

```text
不要笼统说“让它更好”
要说：
- 添加什么功能
- 不要改什么
- 保持什么风格
- 数据从哪里来
- 移动端怎么处理
- 代码要不要简单
```

这会直接决定 Cursor 输出质量。

---

## 2. Debug 能力

你要学会三步：

```text
1. 复制报错
2. 问 AI 解释原因
3. 让 AI 最小修改修复
```

Prompt：

```text
Explain this error in simple terms and fix it with minimal code changes. Do not rewrite the whole project.
```

---

## 3. 接单沟通能力

你以后客户发需求，你要会问：

```text
Do you already have a design?   您是否已有设计稿？
Do you have existing code?      您是否已有现有代码？
Do you need React or plain HTML/CSS? 您需要 React 还是纯 HTML/CSS？
What API should be used?            应该使用哪种 API？
What languages do you need?          您需要哪些语言支持？
What is the deadline?               截止日期是什么时候？
What exactly should be delivered?    具体需要交付哪些内容？
```
